# Implementation notes

Implemented locally on 2026-11-14. React 19.1.1, TypeScript 5.7.3, Vite 6.4.6, MapLibre GL 6.18.0; the explicit ESM worker URL is bundled by Vite. Fonts are bundled Fontsource DM Sans and Pixelify Sans. No paid map key or server is needed.

All 43 original recommendation IDs remain, with the owner's subsequent updates and additions bringing the total to52 entries and32 researched venue branches. Nine park/walk/area guides have explicitly approximate overview anchors, not invented entrances; three walks include named stops and external walking directions, not traced turn-by-turn geometry. Bakeri has two independently saved branches grouped under one parent, with Greenpoint as the default. LIC remains visible with no invented recommendation. Descriptions, personal notes, tips and current visitor-access caveats stay separate; source URLs and dates are retained per location.

The custom palette uses OpenFreeMap/OpenMapTiles and OpenStreetMap geography. Normal vector-tile buildings appear from zoom14. A local bounded overview layer uses real z14 building footprints sampled/simplified for overview only, with 1.35x display-height exaggeration, not survey-grade geometry. The extraction downloaded50 tiles/17,381,878 bytes at at most4 parallel requests with an app-specific User-Agent, within the provider's inspected download terms. `scripts/prepare-overview.mjs` then `scripts/optimize-overview.mjs` regenerate it. Runtime GeoJSON is5,193,636 bytes. Attribution remains on the map. Ferry is decorative, not live tracking. Reduced motion disables its animation; hidden tabs skip position updates.

Saved entries share canonical IDs across map/list/detail, validate localStorage, recover corrupt shapes and sync cross-tab through storage events. Last successful write wins. Denied storage keeps in-memory saves with a warning. Map failure leaves the list usable; clipboard denial presents copyable text. Directions use the researched address, not the visitor's location.

Known limitations: most brands still have one researched branch, not an exhaustive branch directory; broad routes do not provide turn-by-turn geometry. Thirty-two entries have openly licensed real local photos with source credits;20 use original category illustrations. Before the requested Vercel deployment, the owner chose licensed photos only:18 unconfirmed official-site photographs were removed from public assets. Overview buildings remain sampled and bounded, and public map tiles have no SLA. Production JS is about1.55MB (436.2KB gzip), plus the519.6KB map worker. Existing history tracks node_modules; generated dependency noise was not cleaned or included in these updates. The original unused malformed Header is outside the application/typecheck graph.
